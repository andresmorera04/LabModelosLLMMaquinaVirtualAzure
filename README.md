# LabModelosLLMMaquinaVirtualAzure
Laboratorio que a través de IaC con terraform crea una maquina virtual en Azure y los componentes necesarios para esta maquina virtual (Usa una imagen de Ubuntu pre-empaquetada con drivers NVIDIA para uso de LLMs), luego sobre la misma instala y configura el servicio de Ollama y baja 3 modelos definidos por default para este laboratorio
